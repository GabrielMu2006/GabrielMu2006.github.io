# Local content workspace

This directory is for drafts, source material, and pre-publication records. It is outside the Jekyll source and is never deployed to the public website.

- `blogs/`: Blog drafts and source text.
- `notes/`: raw course notes, reading notes, and import material.
- `repositories/`: README snapshots and project-description research.
- `attachments/`: images or documents still being prepared for publication.
- `private/`: optional local-only material ignored by Git.

Published website copies belong in the matching collection under `site/content/`. Do not store passwords, API keys, access tokens, cookies, or unauthorized private material anywhere in the repository.
