今天更新了 Football Simulator 的项目介绍页：该仓库发布了 v1.0.0（首个正式版），README 已重写为正式版文档，介绍页按新 README 更新。

## v1.0.0 主要变化

- 发布 macOS DMG 与 Windows 便携 zip，均通过 GitHub Releases 提供。
- 真实球员池从 200 扩展到 250（新增 50 名高声誉球员）。
- 新增首次启动教程弹窗与顶栏「教程」按钮。
- 队徽升级为 team_badges_40_v2/PNG（V2：无外框、核心图案更大），并放大导航箭头与徽章。
- 存档管理升级：新建 / 选择 / 删除（回收站）/ 备份 / 导出 / 导入。
- 新增快捷键：Cmd/Ctrl+K 搜索、Cmd/Ctrl+Enter 下一周、Cmd/Ctrl+Shift+Enter 到下一待办、Cmd/Ctrl+Alt+Enter 到赛季末、Cmd/Ctrl+Shift+W 本周战报、Cmd/Ctrl+R 刷新。

项目介绍页已更新，可在 /Repositories/football-simulator/ 查看。
