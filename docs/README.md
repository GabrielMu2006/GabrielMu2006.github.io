# Internal project records

This directory keeps historical implementation plans and design notes for the site. These files explain why earlier changes were made, but they are not active runbooks and are excluded from the generated website.

## Source of truth

- [`../AGENTS.md`](../AGENTS.md) is the complete, current maintenance and publishing guide.
- [`../README.md`](../README.md) is the repository overview and local-development entry point.
- [`../test/site_structure_test.rb`](../test/site_structure_test.rb) protects the current structural contract.

## Historical records

- `superpowers/plans/2026-07-10-content-publishing-workflow.md`: original publishing-workflow implementation plan. Its proposed standalone guide was later consolidated into `AGENTS.md`.
- `superpowers/plans/2026-07-10-custom-domain.md`: implementation plan for the custom domain.
- `superpowers/specs/2026-07-10-custom-domain-design.md`: design record for the custom-domain setup.

Treat incomplete checkboxes in historical plans as snapshots from the implementation process, not as the current project status.
